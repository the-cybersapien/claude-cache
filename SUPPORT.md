# Support

- **Bugs and feature requests:** [open an issue](https://github.com/the-cybersapien/claude-cache/issues). Include your Claude Code version (`claude --version`), the cachekeeper version, and what `/cache` printed.
- **Anything else:** email aditya@cybersapien.xyz.

To see what cachekeeper is doing, start Claude Code with `claude --debug-file /tmp/cc.log` and search the log for `cachekeeper`. The [README](README.md) explains each feature, and its "Work machines" section covers organization-managed Claude Code.
